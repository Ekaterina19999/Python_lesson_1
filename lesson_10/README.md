# Проект автоматизации тестирования с интеграцией Allure (Урок 10)

Данный каталог содержит тесты для медленного калькулятора и интернет-магазина Swag Labs, доработанные под стандарты отчетности Allure Framework.

## Базовый синтаксис записи и форматирования Allure

*   **`@allure.step`**: Декоратор используется внутри классов `Page Object` для логирования действий веб-элементов.
*   **`with allure.step("...")`**: Контекстный менеджер применяется внутри тестов для изоляции финальных проверок (`assert`).
*   **Метаданные тестов**:
    *   `@allure.title` — задает понятное название тест-кейса.
    *   `@allure.description` — подробное описание логики теста.
    *   `@allure.feature` — размечает функциональный блок приложения.
    *   `@allure.severity` — определяет критичность теста (`CRITICAL` / `NORMAL`).

## Инструкция по запуску тестов и сборке отчетов

### 1. Формирование результатов
Запустите тесты из корня вашего проекта с указанием целевой папки для хранения логов Allure:

```bash
pytest --alluredir=lesson_10/allure-results lesson_10/
```

### 2. Просмотр интерактивного отчета
Сгенерируйте и откройте HTML-отчет в веб-браузере с помощью встроенного сервера Allure:

```bash
allure serve lesson_10/allure-results
```
